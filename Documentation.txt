This structure itself follows SRP.

| Component            | One responsibility  |
| -------------------- | ------------------- |
| `agent.py`           | Coordinate agents   |
| `recipe_agent.py`    | Recipes             |
| `nutrition_agent.py` | Nutrition           |
| `grocery_agent.py`   | Grocery lists       |
| `event_bus.py`       | Redis communication |
| `repository.py`      | Database            |
| `main.py`            | API                 |
| `index.html`         | UI                  |
